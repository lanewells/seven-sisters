# Seven Sisters

This repo is a frontend website documenting the build process and inspiration behind an art installation called Seven Sisters by artist Caleb Nederhood.

It is custom built by volunteer Lane (Delaney Wells) using React(Vite), TypeScript, and Tailwind CSS, deployed using Vercel.

This site is currently live at https://7sisters.art and is continually updated as the art installation progresses.

Built with assistance from Claude (Anthropic) for debugging and finding resources.
